# 研时

单人使用的本地学习与科研时间规划桌面应用。主界面以 Toggl Track 日历规划视图为视觉参考，数据只保存在本机，不需要账户或网络服务。

## 功能

- 项目和任务管理：预计时长、截止日期、备注、完成状态、项目归档与恢复。
- 3／5／7 天日历：拖动创建计划、从任务库拖入日历、跨天移动、调整时长、编辑和删除计划。
- 编辑计划时使用 24 小时制填写开始和结束时间，例如 13:30 至 15:00。
- 专注计时：从顶部、任务或计划启动，支持暂停、继续、结束；也可补录和编辑实际记录。
- 每周复盘：每日计划与实际、项目投入、时间差和完成任务。
- 本地 JSON 备份与恢复、CSV 时间记录导出、日历偏好设置。

多人协作、客户计费、账户和云服务不在产品范围内。

## 开发

需要 Node.js、Rust MSVC 工具链、Windows C++ Build Tools 与 WebView2。

```powershell
npm install
npm run tauri -- dev
```

只调试前端可运行 `npm run dev`。浏览器预览使用 `localStorage`；桌面版使用应用数据目录中的 `yanshi.db`（SQLite），两者的数据互不共享。

构建 Windows 安装包：

```powershell
npm run tauri -- build
```

安装包位于 `src-tauri/target/release/bundle/`。若 Rust 由系统 MSI 安装且未加入终端 PATH，先在当前终端加入 Rust 的 `bin` 目录。

## 数据与备份

桌面版将整个应用状态作为单条记录写入 SQLite，状态内含数据版本并在读取旧备份时迁移。设置页可导出 JSON 备份并导入恢复；导入会替换当前数据，因此操作前建议先导出一份。CSV 方便在表格软件中分析计划与实际时间。
